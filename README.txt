VEGAMAN WEBSITE — QUICK START (WINDOWS 11)

1. Extract the Vegaman-Website.zip file.
2. Open the extracted folder.
3. Double-click index.html to preview the website in your browser.
4. To edit the website, open index.html, style.css, and script.js in VS Code or another code editor.

FILES
- index.html: page content and SEO metadata
- style.css: responsive design and styling
- script.js: mobile menu and current year
- assets/favicon.svg: browser tab icon
- assets/vegaman-logo.png: your uploaded Vegaman logo

BEFORE PUBLISHING
- Replace hello@vegaman.com in index.html with your real business email.
- Update the About and Services text to match your actual business.
- Your uploaded Vegaman logo is already included in assets/vegaman-logo.png and displayed in the header/footer.
- This is a static front-end website. It does not include a backend, user accounts, or a working contact form.
- Google Fonts are loaded online; the site still works offline with fallback fonts.

PUBLISHING
You can publish this folder with GitHub Pages or another static website host. Keep index.html at the root of the published folder.
